Implement the first playable vertical slice of this game.

Goal: Create a simple playable loop where the player reads dialogue, makes a choice, plays a minigame, and then returns to the story.

Load story data from a JSON file in /story/chapter1.json.

Gameplay behavior:

React loads the starting node.

DialogueBox displays the text.

ChoiceMenu displays buttons for choices.

If the player chooses a normal branch, move to the next node.

If the player chooses a minigame action:

Call GameEngine.startMinigame("click")

Show the Phaser canvas.

The Phaser minigame should be a simple click game:

Player clicks a target multiple times within a few seconds.

When the minigame ends:

Return a score result to React.

Hide the Phaser canvas.

Continue the story.

Architecture rules:

React controls story flow.

Phaser only handles gameplay.

Communication should go through GameEngine methods or events.

Do not directly manipulate Phaser objects from React.

UI behavior:

Dialogue appears above the choices.

When a minigame starts, the canvas appears in the center of the screen.

After the minigame ends, return to the dialogue UI.

Add comments explaining how the React UI triggers the minigame and receives the result.
