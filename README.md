AI-Assisted Narrative Game Prototype (Experimental Project)

This is a small experimental prototype exploring the use of AI-assisted development to rapidly design and scaffold a text-based narrative game system with embedded minigame mechanics.

The project was not developed as a production application or full engineering effort, but rather as a curiosity-driven exploration of AI-generated scaffolding, game design structure, and system design prompting.

My Contribution

My primary role in this project was:

Designing the overall game concept and architecture through structured prompts
Defining the narrative flow, branching story logic, and minigame integration rules
Specifying system constraints and communication patterns between React and Phaser
Iteratively refining the desired behavior through prompt engineering

All core system behavior, implementation scaffolding, and code generation were produced with the assistance of AI tools based on these specifications.

Project Structure
prompts.txt – Original design prompts used to generate system structure and behavior
story/ – JSON-based narrative definitions
Frontend (React) – Handles story flow and UI rendering
Game Engine (Phaser) – Handles minigame execution logic
Purpose of This Project

The goal of this project was to explore:

How effectively AI can translate structured prompts into working software
How to design modular game systems through specification rather than manual implementation
The boundaries between system design and code generation
Important Note

This project is an experimental prototype and should be understood as a learning artifact rather than a production-grade software system.
